# WDD 130 – Web Fundamentals

This repository contains my coursework and projects for **WDD 130: Web Fundamentals**.

## 📚 About the Course

WDD 130 introduces the fundamentals of web development using **HTML** and **CSS**. Throughout the course, I learn how to structure web pages, apply styling, create responsive layouts, and build accessible websites.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* Git and GitHub

## 📂 Repository Contents

This repository includes:

* Weekly assignments
* Practice exercises
* Course projects
* Personal homepage
* White Water Rafting website project

## 🎯 Learning Goals

* Build well-structured HTML documents
* Style web pages using CSS
* Understand basic web design principles
* Develop responsive and user-friendly websites
* Use Git and GitHub for version control.
